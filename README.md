# MiCoding

MiCoding 是一个基于 macOS SwiftUI 的 Xiaomi Bluetooth Remote 2 Pro 配置器。界面借鉴 Logi Options+ 的信息架构、设备画布、动作库与细腻动效，但不使用罗技品牌、字体或美术资源。

应用不包含注册、登录、账号或云同步。下载后即可使用，配置只保存在当前 Mac；只有用户手动检查更新或开启“自动检查软件更新”时，才会读取 GitHub Releases 的公开版本信息。

## 当前版本

- 设备首页与悬浮卡片动效
- 固定 `1180 × 760` 窗口外框和 `1180 × 728` 布局区，锁屏启动、恢复位置和重新打开时保持同一比例
- 首页对齐 Options+ 的停用/启用与移除控制；紧凑电池/蓝牙图标点击后会打开设备状态卡，直接显示 macOS 上报的实时电量、固件并支持刷新。停用状态会降亮设备但保留配置，也可保留配置地移除并重新添加设备；体验推荐可长期关闭
- 首页“探索”进入与 Options+ 同结构的探索中心，按键测试、Actions Ring、应用 Profile 和更多玩法卡片均连接真实页面；Smart Actions 的 AI 分类可直接定位 AI 模板
- 首页顶栏按本地使用场景精简为添加设备、Smart Actions 和设置；完整设备配置可从设备设置直接导入或导出，无需注册或登录
- 设备设置可将按键、手势参数、智能操作与 Actions Ring 导出为本地 JSON 备份，并完整恢复
- “移除设备”会立即停止 MiCoding 输入接管并隐藏设备，保留全部配置供重新添加后恢复，同时打开 macOS 蓝牙设置完成系统级忽略；“清除配置”保留为独立操作
- Xiaomi Remote 2 Pro 设备配置页，包含原版式设备画布、14/12px 分层按键标注、悬停与编辑选中态、手势参数标注、FLOW 引导和分组设置
- FLOW 使用 macOS 通用控制与接力实现跨 Mac 指针切换和通用剪贴板，并可直达对应系统设置
- 13 个可选择的遥控器按键热点
- 当前动作与应用专属配置档案
- 动作搜索、分类、点击分配与拖放分配
- 有效/无效拖放状态和按键回弹反馈
- 无硬件时的当前按键动作测试
- 二十七套本机组合动作模板；模板与已安装动作分离，创建页对齐原版 `如果… / 那么…` 工作流，并支持设备、应用切换、Actions Ring 或全局快捷键触发器，以及应用（打开、关闭、置于前台）、快捷键、文本、网址、系统动作和延迟节点的编辑、拖拽排序、悬停操作、参数校验、试运行、导入导出与按键分配；`New Note` 会在备忘录中真正创建新笔记
- Smart Actions 管理页支持启停、复制、重命名编辑、试运行、分配、导出与删除；停用后不会响应遥控器或全局快捷键触发，重复的全局快捷键会在编辑或重新启用时明确拦截
- AI 回复、语法修改、摘要、英译和代码解释模板会读取当前所选文本，生成各自的任务提示词并打开 ChatGPT；桌面客户端不可用时保留网页与剪贴板兜底
- 通用、输入服务、通知、隐私数据与设备信息页面；设备信息可直达实体按键测试，无需先翻完特性导览
- 通用设置会真实检查 GitHub Releases 并显示当前、可更新、尚未发布或网络失败状态；Actions Ring 支持入口提供应用内使用说明，不保留空链接
- Actions Ring 支持八个主气泡和文件夹式九个子气泡；“工作模式”文件夹可从动作库分配，运行时中央按钮返回主环；音量与亮度参数气泡支持滚轮或水平拖动，并调用 macOS 原生媒体键实时调节
- 跟随系统、浅色和深色三种外观
- 可导出的蓝牙诊断报告，以及可持久化的输入服务、操作反馈、权限、连接状态、低电量与推荐开关；电量首次降到 20% 或以下时提醒一次
- 统一 Lucide 矢量图标系统，不混用 SF Symbols
- 真实 `IOHIDManager` 设备发现与 13 键输入；特性概览会逐键验证并保留本次识别进度，直接显示不同固件产生的未映射 HID Usage
- 动作抽屉顶栏可直接切换单击 / 长按 / 双击，并在多个按键之间保持当前触发层
- 动作抽屉可直接选择任意本机 `.app` 并绑定到单击、长按或双击；配置保存应用路径，未提供 bundle identifier 的本地/自签名 App 也能启动
- 高级键盘映射可录制单独的 `fn`、`⌘` / `⌥` / `⌃` / `⇧` 组合键、F1–F20、方向键与 Home / End / Page Up / Page Down；录制期间会优先捕获 `fn` 和菜单快捷键，即使 macOS 已给 `fn` 配置本地动作，也不会让系统行为抢走本次录制
- 手势与连按页使用可点击参数摘要卡；选中后以 Options+ 同宽右侧抽屉调整长按、双击与防抖，并提供推荐档位和默认值恢复
- 顶栏“＋”打开与 Options+ 同结构的应用选择面板，可浏览本机已安装 App、勾选增删 Profile，并按前台应用自动应用专属配置
- 单击 / 长按 / 双击解析状态机
- `CGEvent`、媒体键、安全网页、默认浏览器、按 bundle identifier 或精确 `.app` 路径启动应用、文本粘贴、可配置延迟与顺序组合执行器
- 前台应用 Profile 自动切换
- 本地 JSON 配置持久化

## 本地数据与权限

MiCoding 不包含分析 SDK，不会发送诊断、使用数据或按键内容。按键配置、应用 Profile、智能操作和界面偏好仅保存在 `~/Library/Application Support/XiaomiRemoteStudio/config.json`。启用自动更新检查时，应用只向 GitHub Releases 请求公开版本元数据。

输入监控权限仅用于读取遥控器 HID 按键；辅助功能权限仅用于执行用户明确分配的快捷键和系统动作。蓝牙诊断报告由用户主动导出，且不包含实际按键内容。

## 运行

在 Xcode 中打开 `Package.swift`，选择 `XiaomiRemoteStudio` scheme 后运行；或在终端执行：

```bash
cd XiaomiRemoteStudio
swift run XiaomiRemoteStudio
```

生成可双击的本地 `.app`：

```bash
./scripts/package-local.sh
open "build/MiCoding.app"
```

打包脚本会优先使用钥匙串中可用的 Apple Development 证书，让输入监控和辅助功能授权在本机覆盖升级后保持有效；没有开发证书时会退回 ad-hoc 签名。也可以通过 `MICODING_CODESIGN_IDENTITY` 显式指定签名身份。
